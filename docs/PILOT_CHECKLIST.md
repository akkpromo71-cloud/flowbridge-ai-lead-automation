# Приёмка перед первым клиентским пилотом

Один экземпляр для одной компании, один mailbox, один follow-up. Отметка IMPLEMENTED означает наличие кода; VERIFIED требует записанного результата в согласованном окружении. Не переносите статус demo в live.

| Проверка | Критерий приёмки | Кто подтверждает |
|---|---|---|
| Бизнес-конфиг | Название, услуги, описания, язык, CTA, approved claims и privacy notice согласованы | Клиент + исполнитель |
| Scoring | Пороги и назначения бюджетов проверены на понятных клиенту примерах; combined не считается оплатой услуг | Клиент |
| Тестовые обращения | Размечены fit/not_fit/unknown, пропуски бюджета, конфликт сроков, RU/EN и injection | Исполнитель |
| LLM sample | Факты сверены отдельно от JSON и score; допустимые omissions и ручной разбор определены | Обе стороны |
| AI draft | Нет неподтверждённых цен/обещаний; модель и версии видны; real generation проверена отдельно | Оператор |
| OpenAI | Ключ принадлежит клиенту, разрешены модель/лимит/расход; дневной token cap и concurrency настроены | Клиент |
| Telegram | Тестовый bot/chat согласован; одно разрешённое уведомление проверено; protected link требует login | Клиент |
| SMTP | From, TLS, mailbox, Message-ID и тестовый адрес явно согласованы; approved version принята провайдером | Клиент |
| IMAP | В тестовом mailbox проверены reply, auto reply, bounce, unmatched, UIDVALIDITY и повторная загрузка | Исполнитель |
| Подтверждение отправки | `provider_accepted` отделено от доставки; процедура delivery_unknown описана и показана | Оператор |
| Follow-up | Один, задержка от acceptance; новая approval; reply/opt-out/closed/stale inbox останавливают | Исполнитель |
| Домен/HTTPS | Домен клиента, валидный сертификат, secure cookies, Origin и proxy проверены | Администратор |
| Доступы | Уникальные admin passwords, срок сессии, разные internal/webhook tokens; editor/DB не публичны | Администратор |
| Backup | Есть расписание и шифрованное хранение БД/секретов n8n; доступ ограничен | Администратор |
| Restore | Backup восстановлен в новую БД, миграция и связи проверены; RPO/RTO согласованы | Администратор |
| Retention | Период хранения и удаление лидов/писем/backup согласованы; demo очищается отдельно | Клиент |
| Privacy | Правила обработки контактов и текста, используемые провайдеры и ответственность приняты | Клиент |
| Opt-out | Оператор умеет остановить коммуникацию; suppression действует перед SEND | Оператор |
| Costs | AI usage, hosting, mailbox, backup и сопровождение разделены; неизвестный usage не ноль | Клиент |
| Monitoring | health/ready, failed/needs_review jobs, mailbox freshness и delivery_unknown видны ответственному | Администратор |
| Support boundary | Срок пилота, объём обращений, окно поддержки, эскалация и acceptance criteria записаны | Обе стороны |

Нельзя начинать пилот по одному успешному AI smoke. Live Telegram/SMTP/IMAP требуют своих credentials, согласованного тестового получателя и отдельного разрешения на отправку. Публичное размещение — отдельное действие.

Безопасный откат: остановить worker и внешние отправки, сохранить неизвестные исходы без повторов, сделать backup, вернуть совместимые приложение/миграцию по [deployment guide](DEPLOYMENT.md). Не переключать live-БД в demo.
